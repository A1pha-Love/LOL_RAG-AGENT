# 装备目录的补丁间漂移（7.11.1–7.18.1）

## 先说边界（最重要）

1. **装备数据不在对局 CSV 内**。`games.csv` 的 61 个字段**没有任何装备字段**，
   因此**本文件不能回答"某场比赛出了什么装备"**，也不能回答某装备的选取率、胜率。
2. **CSV 没有逐场 `patch` 字段**。所以即使知道了装备在某补丁的价格，
   **也无法确定某一场比赛用的是哪个补丁的装备数值**。
3. 本文件描述的是**静态数据快照之间的差异**，用途是解释"同名装备在不同补丁数值不同"
   这一现象，而不是给出任何对局层面的结论。

## 数据来源

项目保存了 8 个 Data Dragon 补丁的完整快照（`ShuJuYuan/ddragon/<patch>/zh_CN/`）：

`7.11.1`、`7.12.1`、`7.13.1`、`7.14.1`、`7.15.1`、`7.16.1`、`7.17.1`、`7.18.1`

每个快照的 `item.json` 自带 `version` 字段，已逐份核对与目录名一致。本文件的数字均由
`scripts/analyse_item_drift.py` 从这些文件直接计算，可复现。

## 口径说明（三种筛选条件，务必区分）

`item.json` 7.17.1 原始 **262** 条。不同用途需要不同筛选，三者数字不同：

| 口径 | 条件 | 7.17.1 条数 |
|---|---|---|
| 原始全部 | 无 | 262 |
| **召唤师峡谷（本文件使用）** | `maps['11']` | **228** |
| **装备目录文档使用** | `maps['11']` 且 `gold.total > 0` | **193** |

- `domain_item_catalog_7.17.1.md` 收录 **193 件**（它以"装备属性与合成关系"为目的，
  排除了 35 条无价条目）。
- **本文件用 228 这一较宽口径**，见「观测一」中对该选择的说明。
- 引用"可用装备数"时**必须说明口径**，193 与 228 相差 35。

**按物品 ID 统计，不按名称**：附魔系列存在同名不同 ID 的条目，例如
`附魔：熔渣巨人` 对应 `1401`、`1409`、`1413`、`3672` 四个 ID（分别对应不同
模式地图池）。按名称统计会把这些合并成一条，从而漏掉各自的调整。

无价条目在期间**恒为 35**，它们是升级态（如炽天使之拥、魔切）、饰品、守卫，
以及特殊商店逻辑的条目（如防御塔类）。**装备目录文档收录的正是"有价"这一列**
（7.17.1 = 193 件），因为它以"装备属性与合成关系"为目的。

**为什么本文件用 228 的较宽口径**：价格与属性漂移可能发生在任何条目上，
先按 228 检测差异、再标注某一条是否在目录中，可以避免检测盲区。
这只是口径选择，不是与目录文档的矛盾。

### 一个容易搞错的字段

`gold.purchasable` **不能当作"有价格"**。实测 7.17.1 的 228 条中：
`total <= 0` 的有 35 条，而 `purchasable === false` 的有 21 条，
**两者只有 18 条重叠**——有 17 条 `total = 0` 却标着 `purchasable = true`
（监视图腾、扫描透镜、防御塔类等）。因此本文件用 `total` 判断有无价格，
不用 `purchasable`。

首尾对比：**新增 10 件、移除 0 件、数值变更 28 件**（价格 16 次 + 属性 12 次）。

其中 7.16.1 → 7.17.1 这一跳**单独新增 8 件且无任何数值变更**；7.17.1 → 7.18.1

## 观测四：期间发生过一次改名

| 物品 ID | 7.11.1 名称 | 7.18.1 名称 |
|---|---|---|
| `3050` | 基克的先驱 | **基克的聚合** |

因此**按名称检索装备会在跨补丁时失效**，稳定的键是物品 ID。

## 为什么这是重要的冲突样本

1. **同名不同值**：同一个装备名（如 `附魔：熔渣巨人`、`骑士之誓`）在不同补丁下价格与属性不同，
   而**CSV 无法指出某场比赛属于哪个补丁**。因此"某装备多少钱"这类问题，
   **只有在明确补丁的前提下才有唯一答案**。
2. **同名不同 ID**：附魔系列存在 4 个同名的不同 ID，按名称统计会漏掉各自的变化。
3. **改名**：`基克的先驱` → `基克的聚合`，说明名称不是稳定标识。

## 引用要求

- 提到装备数值时**必须同时给出补丁版本与物品 ID**，例如
  "`3109` 骑士之誓 在 7.17.1 总价 2300、7.18.1 为 2200"。
- **不得**把装备数值与某场对局关联，CSV 中没有装备字段也没有逐场补丁字段。
- **不得**用本文件推断某装备的选取率或胜率——快照不含任何对局统计。
- 本项目锁定的**主要引用版本是 7.17.1**（与 `domain_item_catalog_7.17.1.md` 一致）；
  引用其他补丁时应显式说明。
