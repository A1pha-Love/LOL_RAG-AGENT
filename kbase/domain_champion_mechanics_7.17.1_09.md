# 英雄机制与技能（7.17.1）第 9 批：ID 53-58

本文件来自 Riot Data Dragon 官方静态数据，用于解释英雄定位、基础属性与技能效果。原始 CSV 的英雄字段只存数值 ID，名称与技能均来自本映射，不代表逐场比赛的补丁版本。

## 蒸汽机器人（布里茨）

- 英雄 ID：`53`
- 英文标识符：`Blitzcrank`
- 定位标签：Tank、Fighter
- 资源类型：法力

### 基础属性

| 属性 | 数值 |
|---|---:|
| 生命值 | 582.6 |
| 生命回复/5秒 | 8.51 |
| 法力值 | 267.2 |
| 法力回复/5秒 | 8.5 |
| 攻击力 | 61.54 |
| 攻击速度偏移 | 0 |
| 护甲 | 24.38 |
| 魔法抗性 | 32.1 |
| 移动速度 | 325 |
| 攻击距离 | 125 |

### 被动：法力屏障

布里茨生命值低于20%时，将激活法力屏障，产生相当于布里茨法力值50%的法力护盾，持续10秒。法力屏障每90秒仅能触发一次。

### 技能

**1. 机械飞爪**

布里茨发射他的右手，来抓取碰到的第一个敌人，在对敌人造成伤害的同时，还会将这名敌人拉到他的面前。

- 冷却：20/19/18/17/16 秒
- 消耗：100（法力）
- 射程：925

**2. 过载运转**

布里茨对自己进行了超级充电，他的攻击速度和移动速度得到了显著提升。他会在效果结束后暂时减速。

- 冷却：15 秒
- 消耗：75（法力）
- 射程：1

**3. 能量铁拳**

布里茨为机械手臂充能，下次攻击造成双倍伤害并击飞目标。

- 冷却：9/8/7/6/5 秒
- 消耗：25（法力）
- 射程：300

**4. 静电力场**

被动地会对周围的某个敌方单位造成闪电伤害。在主动施放时，会对周围的敌人造成伤害和0.5秒的沉默效果，但是主动效果施放后会移除被动效果，直到技能冷却完毕。

- 冷却：60/40/20 秒
- 消耗：100（法力）
- 射程：600

### 使用提示

- - 机械飞爪、能量铁拳和静电力场的1-2-3组合可以摧毁一名落单的对手。
- - 使用布里茨的抓取将一名敌人拉入你们的防御塔射程内，继而一记能量铁拳可以让防御塔对他们进行多发射击。

### 对抗提示

- - 布里茨的被动技能【法力屏障】能够在他濒死时提供一个吸收伤害的护盾。
- - 躲在小兵后面能够防止被布里茨抓。布里茨的机械飞爪只能够抓住第一个碰到的敌人。

### 被动：花岗岩护盾

墨菲特被岩石护盾保护，最多吸收最大生命值10%的伤害，若10秒内未受到攻击，护盾将重置。

### 技能

**1. 地震碎片**

墨菲特使用元素原力，将一块岩石碎片从地下射向敌人，对其造成伤害并偷取其移动速度4秒。

- 冷却：11/10/9/8/7 秒
- 消耗：50/55/60/65/70（法力）
- 射程：625

**2. 野蛮打击**

墨菲特挥击的力量如此之大，以至于他的攻击会对前方的所有敌人造成伤害。此外，这个技能还会被动提升他的护甲值。

- 冷却：12 秒
- 消耗：25（法力）
- 射程：400

**3. 大地震颤**

墨菲特锤击地面，放射出冲击波对目标造成基础伤害，并根据墨菲特的护甲值附加额外伤害，同时暂时减低目标攻击速度。

- 冷却：7 秒
- 消耗：50/55/60/65/70（法力）
- 射程：400

**4. 势不可挡**

墨菲特冲击目标区域，将所有敌人抛向空中，造成魔法伤害并晕眩。

- 冷却：130/115/100 秒
- 消耗：100（法力）
- 射程：1000

### 使用提示

- - 护甲能降低花岗岩护盾在承受敌方攻击时的损耗速度，因此在敌人摧毁护盾前激活野蛮打击，可以加强护盾对物理伤害的承受能力。
- - 虽然他的多数技能可通过护甲来提升伤害，但有些对局还是需要墨菲特拥有魔法抗性。当这种情况出现时，可以试试购买军团圣盾，水银之靴以及守护天使等物品。

### 对抗提示

- - 若你是物理伤害英雄，攻击墨菲特时站在友军后方。大地震颤会极大地减少你的伤害。
- - 墨菲特是少数具备打野能力的坦克之一。如果看到墨菲特带了惩戒，就要当心了。

### 技能

**1. 梦魇之径**

魔腾扔出一把暗影之刃，对敌人造成伤害并留下幽灵影径，并使受到伤害的敌方英雄也留下幽灵影径。在影径上时，魔腾无视任何碰撞体积，并且他的移动速度和攻击力也会得到提高。

- 消耗：50（法力）
- 射程：20

**3. 无言恐惧**

- 冷却：15/14/13/12/11 秒
- 消耗：60/65/70/75/80（法力）
- 射程：425

**4. 鬼影重重**

魔腾减少所有敌方英雄的视野范围，并在此过程中移除敌方英雄的友军的视野。魔腾能够借机突进到附近的敌方英雄身边。

- 冷却：150/125/100 秒
- 消耗：100（法力）
- 射程：2500/3250/4000

### 使用提示

- - 在千钧一发之际施放大招是非常划算的，即使你不能用它来突进。
- - 梦魇之径不仅是攻击技能，还可以让你远离战斗或者从必死的境地之中逃脱。
- - 在大招突进时使用黑暗庇护，也许会让恐慌的敌人在你的护盾上浪费一次限制技能。

### 对抗提示

- - 当魔腾施放大招时，和友军站近一点儿，这样才能一起以众敌寡！
- - 魔腾的无言恐惧有范围限制，所以预留好你的移动技能，好在魔腾施放此技能时逃开。

### 对抗提示

- - 茂凯在使用扭曲突刺时不会受到伤害，所以不要在这时浪费你的技能。

### 被动：怒之领域

雷克顿每次主动攻击都能获得怒气。这些怒气能强化他的技能。此外，雷克顿在低生命值时能获得额外怒气。

### 技能

**1. 暴君狂击**

雷克顿挥动他的武器，对周围所有目标造成中等水平物理伤害，并根据造成的伤害来治疗自己。如果他有50点以上怒气，那么此技能的伤害和治疗效果会得到提升。

- 冷却：8 秒
- 消耗：0（无消耗或50怒气）
- 射程：325

**2. 冷酷捕猎**

雷克顿两次挥击目标，对其造成中等水平物理伤害并晕眩他们0.75秒。如果雷克顿有50点以上怒气，他会三次挥击目标，对其造成更高的物理伤害，并晕眩他们1.5秒。

- 冷却：13/12/11/10/9 秒
- 消耗：0（无消耗或50怒气）
- 射程：300

**3. 横冲直撞**

雷克顿冲向前方，对沿途的敌人造成伤害。如果雷克顿有50点以上怒气，就会造成额外伤害，并减少沿途敌人的护甲值。

- 冷却：18/17/16/15/14 秒
- 消耗：0（无消耗或50怒气）
- 射程：450

**4. 终极统治**

雷克顿转换为暴君形态，获得额外生命值，并对周围敌人造成伤害。此形态的雷克顿定时获得怒气。

- 冷却：120 秒
- 消耗：0（无消耗）
- 射程：20

### 使用提示

- - 横冲直撞非常适合骚扰。先释放技能突入，触发后使用直撞返回安全的位置。
- - 狂怒状态下暴君狂击可以汲取额外的生命值，你可以借此让敌人错误的低估你。
- - 冷却缩减对雷克顿来说是不错的属性，可以迅速获得并使用怒气。

### 对抗提示

- - 在雷克顿有足够怒气时，要格外小心，因为它通常标志着他准备发起攻击了。
- - 通过持续骚扰雷克顿，阻止其进行攻击并获得怒气，能极大降低他的技能效果。
