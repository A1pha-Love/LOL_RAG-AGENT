# 英雄机制与技能（7.17.1）第 12 批：ID 76-81

本文件来自 Riot Data Dragon 官方静态数据，用于解释英雄定位、基础属性与技能效果。原始 CSV 的英雄字段只存数值 ID，名称与技能均来自本映射，不代表逐场比赛的补丁版本。

## 狂野女猎手（奈德丽）

- 英雄 ID：`76`
- 英文标识符：`Nidalee`
- 定位标签：Assassin、Fighter
- 资源类型：法力

### 基础属性

| 属性 | 数值 |
|---|---:|
| 生命值 | 540 |
| 生命回复/5秒 | 6.008 |
| 法力值 | 295.6 |
| 法力回复/5秒 | 6 |
| 攻击力 | 53 |
| 攻击速度偏移 | -0.02 |
| 护甲 | 22.88 |
| 魔法抗性 | 30 |
| 移动速度 | 335 |
| 攻击距离 | 525 |

### 被动：寻觅

在穿越草丛进行移动时，奈德丽的移动速度会提升10%，持续2秒，并在朝着1400码内的出现在己方视野内的敌方英雄进行移动时，移动速度加成会提升至30%。在【Q标枪投掷】或【W丛林伏击】对敌方英雄或野怪造成伤害后，奈德丽会开始捕猎目标英雄，提供其真实视野，持续4秒。在此期间，奈德丽获得10%移动速度加成（在她朝着被捕猎的目标移动时，这个加成会提升至30%）并且她的【Q推倒】和【W猛扑】会对这些目标造成强化伤害。

### 技能

**1. 标枪投掷**

人类形态： 奈德丽向她的目标投掷标枪，飞行中击中目标造成伤害。美洲狮形态： 她的下一次攻击会试图对目标造成致命伤害，目标的生命值越低，造成的伤害越大。

- 冷却：6 秒
- 消耗：50/60/70/80/90（法力）
- 射程：1500

**2. 丛林伏击**

人类形态下， 奈德丽会对指定位置放置一个陷阱，踩中陷阱的单位的视野将会被暴露给奈德丽，并持续受到伤害。美洲狮形态下，她会猛扑向目标，落地时造成少量伤害。“猛扑”不受冷却缩减的影响。

- 冷却：13/12/11/10/9 秒
- 消耗：40/45/50/55/60（法力）
- 射程：900

**3. 野性奔腾**

人类形态： 奈德丽引导美洲狮的灵魂以治疗友方单位，并且短暂提升他们的攻击速度。美洲狮形态： 她迅速的挥爪攻击她面前的敌人。

- 冷却：12 秒
- 消耗：60/75/90/105/120（法力）
- 射程：600

**4. 美洲狮**

奈德丽转变成美洲狮形态，获得全新技能。

- 冷却：3 秒
- 消耗：0（无消耗）
- 射程：20

### 使用提示

- - 好好利用草丛！进出草丛可以大大影响你在战斗中的效果。
- - 在团战开始时，用你的【Q标枪投掷】压制敌人，然后切换到美洲狮形态去追击被捕猎的目标。
- - 【W丛林伏击】的陷阱会根据猎物的当前生命值来造成伤害。把它们放在己方队伍的后排，就可以在对面冲锋时帮助你的队伍对敌方的前排英雄造成伤害。

### 对抗提示

- - 奈德丽的【捕猎】减益效果只能通过【Q标枪投掷】和【W丛林伏击】来施加。注意躲闪这些技能，就能降低她追加伤害的能力。
- - 奈德丽的【Q标枪投掷】的飞行距离越远，造成的伤害就越高。如果她从远处投掷标枪，那么就一定要躲避她的标枪了。
- - 奈德丽的【Q推倒】会对被捕猎的目标造成额外伤害，但她需要先近身才能使用这个技能。把你的控制技能或防御技能留到她过来拿人头的时候再用吧。

- 资源类型：法力

| 魔法抗性 | 32.1 |

### 被动：灵猴敏捷

转换姿态时，乌迪尔提升攻击速度和移动速度，持续5秒。该效果可以叠加多次。

### 技能

**1. 猛虎姿态**

猛虎姿态：激活效果—乌迪尔暂时提升攻击速度。持续效果—乌迪尔的第一次攻击和之后的每第三次攻击，将会在2秒里持续造成高额伤害。

- 冷却：6 秒
- 消耗：45（法力）
- 射程：600

**2. 灵龟姿态**

灵龟姿态：激活效果—乌迪尔获得短暂的护盾以吸收伤害。持续效果—乌迪尔的第一次攻击和之后的每第三次攻击会治疗他，治疗量相当于他2.5%的最大生命值。

- 冷却：6 秒
- 消耗：45（法力）
- 射程：600

**3. 巨熊姿态**

巨熊姿态：激活效果—乌迪尔短暂的大幅提升移动速度。持续效果—乌迪尔的攻击晕眩目标1秒。该效果不能短时间内作用于同一个目标。

- 冷却：6 秒
- 消耗：45（法力）
- 射程：600

**4. 火凤姿态**

火凤姿态：激活效果—乌迪尔喷射烈焰给附近的敌人造成伤害。持续效果—乌迪尔的第一次攻击和之后的每第三次攻击，将会喷射出火焰来吞没他面前的敌人。

- 冷却：6 秒
- 消耗：45（法力）
- 射程：325

### 使用提示

- - 切换龟灵状态后，护盾吸收的伤害是计算过魔抗和护甲之后的。因此，购买防御道具可以大大地增加你的存活力。
- - 乌迪尔是游戏中最好的打野英雄之一。利用这点可以让你的队伍有很大的经验优势，并能很好地控制地图。

### 对抗提示

- - 乌迪尔通常从野区出现，偷袭兵线上的玩家。在重要位置放置侦查守卫来掌握他的动向。
- - 一旦初始的护盾消逝，灵龟姿态在对抗其他英雄时就会很无力。猛烈攻击，迫使他转换姿态，阻止他回复生命。
- - 有些乌迪尔玩家购买坦克物品来增强生存能力，你可以转而攻击他相对比较弱的队友。

### 被动：钢铁大使

波比扔出她的圆盾，获得攻击距离加成和并造成额外魔法伤害。圆盾会落在附近的一个区域上，并且波比可以拾取它来获得一个护盾效果。敌人可以踩在圆盾上来将它摧毁。

### 技能

**1. 圣锤猛击**

波比挥舞她的铁锤，造成伤害并创造一个区域，这个区域会减速敌人并在一段时间后爆炸。

- 冷却：9/8/7/6/5 秒
- 消耗：35/40/45/50/55（法力）
- 射程：430

**2. 坚定风采**

波比被动获得护甲和魔法抗性。这个加成会在她生命值较低时得到提升。波比可以主动施放此技能来阻挡附近敌人的突进，并获得移动速度加成。

- 冷却：24/22/20/18/16 秒
- 消耗：50（法力）
- 射程：400

**3. 英勇冲锋**

波比冲向目标并把目标推后。如果目标被推到墙上，就会受到晕眩效果。

- 冷却：14/13/12/11/10 秒
- 消耗：70（法力）
- 射程：425

**4. 持卫的裁决**

波比引导一次能够把敌人击飞到远方的锤击。

- 冷却：140/120/100 秒
- 消耗：100（法力）
- 射程：500

### 使用提示

- - 被动技能【钢铁大使】的圆盾会倾向于落在墙体附近，尽量利用这点来让【E英勇冲锋】发挥作用。
- - 可以立刻施放【R持卫的裁决】来击退敌人，你可以在单挑中利用这个特点来赚取优势。

### 对抗提示

- - 波比可以用她的【W坚定风采】来阻挡敌人的突进。
- - 当波比开始旋转她的铁锤时，就说明她在给她的大招【R持卫的裁决】蓄力。
- - 你可以踩在波比的盾上，来阻止它为她提供护盾。

- 英雄 ID：`79`

- 定位标签：Fighter、Mage
- 资源类型：法力

### 基础属性

| 属性 | 数值 |
|---|---:|
| 生命值 | 583.52 |
| 生命回复/5秒 | 5.5 |
| 法力值 | 400 |
| 法力回复/5秒 | 6 |
| 攻击力 | 61.38 |
| 攻击速度偏移 | 0 |
| 护甲 | 29.05 |
| 魔法抗性 | 32.1 |
| 移动速度 | 330 |
| 攻击距离 | 125 |

### 被动：欢乐时光

古拉加斯每次使用技能后都会喝一小杯，立即恢复6%的最大生命值。这个效果每8秒内只会触发1次。

### 技能

**1. 滚动酒桶**

古拉加斯将酒桶滚到目标地点，酒桶可以被主动引爆或在到达目标地点4秒后自行爆炸。被酒桶炸到的敌人，移动速度会被降低。

- 冷却：11/10/9/8/7 秒
- 消耗：60/65/70/75/80（法力）
- 射程：850

**2. 醉酒狂暴**

古拉加斯狂饮酒桶里的佳酿，持续1秒。在喝完之后，他会因醉酒而得到强化，下次普通攻击会对附近的所有目标造成更多伤害，并且自身所受的伤害会降低。

- 冷却：8/7/6/5/4 秒
- 消耗：30（法力）
- 射程：20

**3. 肉弹冲击**

古拉加斯向目标区域冲锋，在撞上第一个敌人后，对附近的所有敌方单位造成伤害和晕眩效果。

- 冷却：16/15/14/13/12 秒
- 消耗：50（法力）
- 射程：600

**4. 爆破酒桶**

古拉加斯向目标区域投掷他的酒桶，对爆炸范围内的所有敌人造成伤害和击退效果。

- 冷却：120/100/80 秒
- 消耗：100（法力）
- 射程：1000

### 使用提示

- - 醉酒狂暴的伤害减免效果在开始引导时就会生效，因此尽量在即将受到伤害时使用它。
- - 尽量使用爆破酒桶将敌人击退到你的防御塔下。
- - 尽量将肉弹冲击与爆破酒桶联合使用，来为你的队伍制造杀机。

### 对抗提示

- - 古拉加斯能够用其终极必杀技击退所有人。注意不要被撞向他，或者更糟——被撞向敌方防御塔。
- - 肉弹冲击的冷却时间很短，你很难追赶古拉加斯，不要过分追赶。

### 被动：圣盾庇护

每攻击或施法4次后，潘森就可以格挡下一次普通攻击或防御塔攻击。

### 技能

**1. 长矛飞掷**

潘森向一个敌人猛掷他的长矛，对敌方目标造成伤害。

- 冷却：4 秒
- 消耗：45（法力）
- 射程：600

**2. 圣盾打击**

潘森跳向一名敌人，并对目标敌人进行盾击，造成伤害和晕眩效果，同时刷新圣盾庇护。

- 冷却：13/12/11/10/9 秒
- 消耗：55（法力）
- 射程：600

潘森使用长矛向前方锥形范围发动三连击，对范围内所有敌人造成伤害。同时潘森也变得更了解敌人的弱点，从而让他总能对生命值低于15%的敌人进行暴击。

- 冷却：10/9/8/7/6 秒
- 消耗：45/50/55/60/65（法力）
- 射程：400

**4. 堕天一击**

潘森积蓄力量腾空而起，轰击目标区域，落地时对目标区域内的敌人造成伤害。离落点越近的敌人，受到的伤害越高。

- 冷却：150/135/120 秒
- 消耗：100（法力）
- 射程：5500

### 使用提示

- - 使用圣盾打击后迅速来一招穿心长矛，可以摧毁你的敌人。
- - 在战斗中经常使用长矛飞掷与增强攻击速度的道具可以通过圣盾庇护来帮助防御。
- - 使用堕天一击来穿越地图并协助友军可以很快扭转战局，让友军占据上风。

### 对抗提示

- - 藏身于草丛中，能够让潘森难以对你使用堕天一击。
- - 当潘森和拥有晕眩或诱捕技能的同伴（如莫甘娜，赛恩）在一起时，你要小心，因为他能够用穿心长矛技能对你造成毁灭性伤害。
- - 潘森的圣盾打击的护盾效果会格挡一次敌方英雄的普通攻击，甚至是一次敌方防御塔的攻击，但在他身上没有护盾效果时，会相对脆弱一些，直到他通过普攻和技能再次获得护盾为止。

### 被动：咒能高涨

伊泽瑞尔的任何技能在击中目标后，都会提升他的攻击速度（最多可叠加5次）。

### 技能

**1. 秘术射击**

伊泽瑞尔发射一枚能量弹，如果它击中一个敌方单位，那么它将减少伊泽瑞尔所有技能1.5秒的冷却时间。

**2. 精华跃动**

伊泽瑞尔发射一道起伏的能量波，将对波纹所经过的敌方英雄造成伤害，同时提升所经过的友方英雄的攻击速度，持续5秒。

- 冷却：9 秒
- 消耗：50/60/70/80/90（法力）
- 射程：1000

**3. 奥术跃迁**

伊泽瑞尔传送到附近的目标区域，并向最近的敌人发射一束自动寻敌的魔法箭。

- 冷却：19/17.5/16/14.5/13 秒
- 消耗：90（法力）
- 射程：475

**4. 精准弹幕**

伊泽瑞尔进行1秒的蓄力，来发射一个强力的能量弹幕，弹幕将对沿途的每一个敌人造成魔法伤害。（每穿过一个单位，弹幕造成的伤害就会降低10%）。

- 冷却：120 秒
- 消耗：100（法力）
- 射程：20000

### 使用提示

- - 使用奥术跃迁来使你的其他技能更容易命中。
- - 你可以将伊泽瑞尔作为一个物理系后期或者法系后期来玩，这取决于你如何升级技能和出装备。
- - 你可以施放精准弹幕来攻击多波小兵，甚至怪物。

### 对抗提示

- - 伊泽瑞尔很脆弱，你可以优先攻击他。
- - 伊泽瑞尔完全凭借技能攻击，你可以躲在小兵旁边，利用小兵来躲避他的技能。
- - 秘术射击可以附带攻击特效，包括召唤师峡谷中绯红印记树怪的增益（燃烧+减速）。
