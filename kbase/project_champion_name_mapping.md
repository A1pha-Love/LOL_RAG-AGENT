# 英雄名称映射与版本边界

## 映射来源

使用 Riot Data Dragon **7.17.1** 的 zh_CN 英雄静态数据。
映射文件保留全部 **138 个**数据英雄 ID 的官方字段：

- `name`：中文名称，例如 ID 1 对应"黑暗之女"。
- `title`：中文称号，例如 ID 1 对应"安妮"。
- `english_id`：英文标识符，例如 `Annie`。
- `aliases`：需要额外兼容的历史名称。

## 关键事实

- **原始 CSV 的英雄字段只存数值 ID，不含英雄名称。**
- 名称映射**只在查询与展示时使用**，不是原始数据的一部分。
- 调用统计工具时统一通过 `champion_id` 参数传入数值 ID、中文名、中文称号或英文标识符。
- 匹配是**精确匹配，不做模糊匹配**。
- 按全量 138 个 ID 核对，`name`、`title`、`english_id` 均存在，且**无跨英雄名称冲突**。

## CSV 中的哨兵值

CSV 的英雄字段出现 **139** 个不同取值，其中 `-1` 是**空禁用位的哨兵值，不是英雄**。
因此可映射的是 138 个英雄 ID。数据集自带的 `champion_info.json` 中
`id=-1`、`name=None` 的占位条目印证了这一点。

## 版本边界（必须说明）

- 数据覆盖 2017-06-08 至 2017-09-06，**跨越多个补丁**，但 **CSV 不含逐场 patch 字段**。
- 7.17.1 是**静态快照**，只用于名称查询与展示，
  **不能证明每一场比赛发生时的名称或精确补丁**，也不能用于按补丁切片。
- 英雄 ID 6 的中文名称在不同补丁间发生过变化：7.14.1 为"首领之傲"，
  自 7.15.1 起为"无畏战车"。项目采用 7.17.1 的名称，并把旧名称作为兼容别名。
  详见版本冲突样本文档。
