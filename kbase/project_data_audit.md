# 数据审计结果与字段取值分布

本文件记录对原始 CSV 的只读审计结果。审计过程以只读方式打开源文件，
不写回、不转换、不清理。

## 文件结构

原始 CSV 的规模与结构：**共 51,490 数据行、61 个字段（列）**。
按 `gameId` 去重后为 **51,053 场**对局，即 437 条重复行；去重规则见
「去重规则与重复数据处理」。

- 数据行数（原始行数）：**51,490**
- 字段数（列数）：**61**
- 字段数不一致的行：0
- 缺失值：**没有任何字段存在空值**
- 无法解析的数值：**0 处**（`gameDuration`、`creationTime` 及各队伍目标字段均可解析）

**注意区分**：原始行数 51,490 是文件里的行数，去重后的对局数是 51,053，
回答"有多少场比赛"时应使用去重后的数。

## `winner` 取值分布

| 取值 | 数量 |
|---|---:|
| `1`（team1 胜） | 26,077 |
| `2`（team2 胜） | 25,413 |

两者接近，不存在明显的队伍侧偏差。

## 首个事件字段取值分布

| 字段 | `0` 未发生 | `1` team1 | `2` team2 |
|---|---:|---:|---:|
| `firstBlood` | 555 | 26,113 | 24,822 |
| `firstTower` | 1,213 | 25,861 | 24,416 |
| `firstInhibitor` | 6,276 | 23,054 | 22,160 |
| `firstBaron` | 20,258 | 14,758 | 16,474 |
| `firstDragon` | 2,000 | 24,690 | 24,800 |
| `firstRiftHerald` | 26,179 | 12,948 | 12,363 |

注意 `0` 的数量差异很大：一血几乎每场都发生（仅 555 场未发生），
而首个峡谷先锋有 26,179 场未发生。这说明**各事件的发生率分母虽相同，但条件胜率的分母差别很大**。
