# 去重规则与重复数据处理

## 原始规模

- 数据行数：**51,490**
- 字段数：61
- 字段数不一致的行：0

## 重复情况

- 重复的非空 `gameId` 出现次数（每组首条以外）：**437**
- 分布在 **424** 个重复 ID 组中
- 对 437 条重复出现逐项比对 61 个字段：**全部与对应首条完全一致，0 组字段冲突**
- 去重后唯一对局数：**51,053**

## 处理规则

1. 分析时**按 `gameId` 去重**，每条 `gameId` 保留一行。
2. **原始 CSV 保持只读**，不做写回、转换或原地清理。
3. 若同一 `gameId` 出现**内容不一致**的重复行，程序必须**报错而不是静默择一**，
   因为那意味着数据源本身有问题。
4. 报告指标时说明使用的是去重后的对局口径，而不是原始行数。

## 容易混淆的地方

- **原始行数（51,490）与去重场数（51,053）不是同一个数**，回答数据规模问题时必须区分。
- 重复行数 437 与重复 ID 组数 424 也是两个不同的数：有些 `gameId` 出现了三次以上。
