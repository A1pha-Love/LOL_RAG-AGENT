# 数据字段定义与取值域

原始文件 61 列的语义，依据数据集官方字段说明确认（不再依赖二手转述）。

## 字段语义与颜色方约定

- `team1` / `team2` 是**对局内两支队伍的字段标识**，用于在同一场比赛内关联队伍、
  事件、英雄与胜负。
- 它们**不代表蓝方/红方**，不代表主客队、先后顺序或优势方。
- 因此**不能按蓝方/红方拆分或比较胜率**；数据中也没有任何颜色方字段。
- CSV 的列名是英文，取值是数字编码，语义见下文各节。

## 数据时间范围与时间戳

- `creationTime` 是**毫秒级 Unix 时间戳**，解析后覆盖
  **2017-06-08T03:14:54.922Z 至 2017-09-06T14:15:32.198Z（UTC）**。
- 这是历史样本，**不能代表当前版本**，也不能用于回答当前版本或当前强势英雄的问题。
- `seasonId` 在本数据中**全部为 9**，所以按赛季切片没有实际意义。

## 胜负与首个事件的取值编码

- `winner`：`1 = team1`，`2 = team2`。观测值只有 `1` 和 `2`，不存在平局或空值。
- 以下字段取值 **`1 = team1`，`2 = team2`，`0 = 无人/未发生`**：

  - `firstBlood`：一血
  - `firstTower`：首座防御塔
  - `firstInhibitor`：首个水晶兵营
  - `firstBaron`：首条纳什男爵
  - `firstDragon`：首条巨龙
  - `firstRiftHerald`：首个峡谷先锋

- `0` 表示该事件在整场比赛中**没有发生**，不是"未知"，也不计入条件胜率的分母。
- 用这些字段比较时必须区分两种分母：**发生率用全部对局**，
  **条件胜率用事件已发生的对局**。

## 英雄与召唤师技能

每队 5 名英雄，每个英雄 2 个召唤师技能：

- `t{1,2}_champ{1..5}id`：英雄的**数值 ID**（不是名称）。
- `t{1,2}_champ{1..5}_sum1` / `_sum2`：召唤师技能的**数值 ID**。
  本数据只用到 9 个技能 ID，全部可映射（见召唤师技能文档）。
  **该字段此前在项目中完全未被使用。**

## 队伍目标数

每队 5 个目标累计击杀数，均为非负整数：

- `t{1,2}_towerKills`：推塔数，观测 0~11
- `t{1,2}_inhibitorKills`：摧毁兵营数，观测 0~10
- `t{1,2}_baronKills`：男爵击杀数，观测 0~5
- `t{1,2}_dragonKills`：巨龙击杀数，观测 0~6
- `t{1,2}_riftHeraldKills`：峡谷先锋击杀数，观测 0~1

这些是**对局结束时的累计值**，不代表目标取得的时间或顺序，
也不代表过程。**该组字段此前在项目中完全未被使用。**

## 禁用

- `t{1,2}_ban{1..5}`：禁用的英雄数值 ID。
- `-1` 表示空禁用位，不是英雄。

## 明确不存在的字段

数据中没有：玩家或账号标识、分路/位置、逐场补丁版本、装备选择、
逐分钟经济或经验、具体技能释放记录。因此相关问题一律无法回答。
