# LoL Ranked Data Agent 最终验收记录

- 验收范围：本地 MVP（数据分析工具、LangGraph Agent、文档 RAG、命令行入口及项目文档）。
- 记录日期：2026-10-08（Asia/Shanghai）。
- 验收方式：整理已有阶段性运行结果，检查本地配置/索引文件状态，并复核评测配置；本次文档整理未调用模型 API，也未重跑完整回归。
- 结论：**本地 MVP 阶段性通过；已知数据范围和评测限制需随项目一起说明。未发布、未部署。**

## 交付内容

1. **数据与口径**：审计本地 `ShuJuYuan/games.csv`。原始表 51,490 行、61 列；51,053 个唯一 `gameId`；437 条重复行分布在 424 个重复 ID 组，重复记录逐字段一致。统计按 `gameId` 去重，不修改原始文件。
2. **确定性统计**：实现数据概览、对局计数、英雄统计、Ban 统计、首个事件发生率/条件胜率和平均对局时长工具。统计数值由本地 Python 计算，不让模型估算。
3. **英雄映射**：使用 Riot Data Dragon 7.17.1（zh_CN）静态数据，覆盖 138 个英雄 ID；name/title/英文标识符均已检查，名称解析无跨英雄冲突。映射只服务查询与展示。
4. **Agent 与 RAG**：LangGraph 单 Agent 结合 Qwen 对话模型和本地工具；LangChain Embeddings 适配 DashScope Qwen 文本 Embedding；SQLite 保存文档向量和来源元数据。知识源为指标字典、映射说明和数据审计报告。
5. **安全与运行体验**：`.env` 保存 API 配置并被 Git 忽略；源 CSV 与生成的 SQLite 索引也被忽略。命令行入口设置 UTF-8 输出；对 API 错误和索引缺失设有明确提示。

## 已知限制与后续范围

- `docs/metric_dictionary.md` 仍为“初稿”。`winner`、`first*` 等字段解释依赖公开的二手字段说明，尚未用原始数据集元数据独立核实；对外发布指标前应完成核实。
- 数据跨越多个补丁，但没有逐场 patch 字段；不能回答当前版本、逐场补丁、分路、玩家或逐分钟过程问题。英雄名使用 7.17.1 静态快照仅用于名称映射。
- 检索阈值 0.3703 是临时值，依据有限代表性查询校准；未来新增真实问法后再校准。
- 自动答案包含/禁止短语检查只能做筛查，无法完整理解语义或否定范围；重要答案仍需人工复核。
- 最新提示词未经过第二次完整 10 案例回归。当前记录遵循“完整套件只运行一次、后续按额度优先复测关键案例”的约定。
- 本项目没有线上部署、发布流程或用户界面；当前交付目标为本地可运行 MVP。

## 常用命令

从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts\chat_agent.py "这份数据去重后有多少场比赛？"
.\.venv\Scripts\python.exe scripts\index_knowledge.py
.\.venv\Scripts\python.exe scripts\evaluate_rag.py --case-id first_blood_two_rates --case-id champion_name_mapping_query
```

Agent、索引和评测命令会分别调用 Chat API 或 Embedding API，并可能产生费用。完整 10 案例命令本次不再运行。
